# 🏡 Luxury Real Estate Platform

A modern, elegant, and responsive real estate web application designed to help users explore properties, discover their dream homes, and connect with real estate agents.

## ✨ Features

- 🏠 **Property Listings** – Browse available residential and luxury properties.
- 🔍 **Smart Search** – Search properties by location, property type, and budget.
- 🎯 **Advanced Filters** – Filter listings based on user preferences.
- 📄 **Property Details** – View property information, images, pricing, and descriptions.
- ❤️ **Favorites** – Save preferred properties for quick access.
- 📩 **Enquiry Form** – Contact agents to request more information.
- 👨‍💼 **Agent Information** – Explore property agent details.
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- ✨ **Premium UI** – Elegant luxury theme with navy blue and gold accents.

## 🎨 Design Theme

- **Primary Color:** `#142D3F`
- **Accent Color:** `#C59D5F`
- **Style:** Modern, minimal, premium, and professional.
